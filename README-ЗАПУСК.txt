ЗАПУСК СИСТЕМЫ «АНАЛИТИКА ЭФФЕКТИВНОСТИ» (ФАВОРИТ ДИВАН)
================================================================

1. САМЫЙ БЫСТРЫЙ СПОСОБ
----------------------------------------------------------------
   Двойной клик по start.bat → откроется браузер:
   http://127.0.0.1:8082/analytics.php

   Черное окно — это сервер. Закрыть окно = остановить сайт.
   Если порт занят, поменяйте в start.bat строку set "PORT=8082".

2. ЧЕРЕЗ OPENSERVER
----------------------------------------------------------------
   1. Скопируйте папку в OpenServer\domains\
   2. Запустите OpenServer, выберите PHP 8.2 или выше
   3. Откройте http://имя-папки/analytics.php
      (если переименуете папку в favorit — http://favorit/analytics.php)

   MySQL 8.4 (Open Server):
     - запустите модуль MySQL 8.4 в Open Server;
     - откройте phpMyAdmin → вкладка «SQL» и выполните содержимое mysql-init.sql
       (или создайте базу favorit_db с кодировкой utf8mb4 вручную);
     - подключение по умолчанию: host 127.0.0.1, port 3306, база favorit_db,
       пользователь root, пароль пустой. При необходимости задайте DB_HOST,
       DB_PORT, DB_NAME, DB_USER, DB_PASS в конфигурации PHP;
     - при первом открытии страницы таблицы, пользователь manager и демо-данные
       создадутся автоматически. У пользователя MySQL должны быть права на CREATE,
       ALTER, SELECT, INSERT, UPDATE и DELETE для favorit_db;
     - чтобы приложение не переключалось на SQLite при ошибке подключения,
       задайте переменную окружения DB_DRIVER=mysql. Иначе доступен SQLite-резерв.
   Если MySQL недоступен, система сама переключится на SQLite:
     - файл базы: data/favorit.sqlite (или папка из FAVORIT_DATA_DIR);
     - схема и демо-данные создаются автоматически.

3. ВХОД
----------------------------------------------------------------
   Кнопка «Вход» внизу меню.
   Логин:  manager
   Пароль: manager123
   Роль:   администратор (может менять роли, планы, делать бэкап)

   Гость видит только цифры и таблицы, без форм.

4. ЧТО ЕСТЬ В СИСТЕМЕ
----------------------------------------------------------------
   Дашборд          — 4 KPI, мини-графики, сводный график,
                      блок «Что видно по данным», прогноз выручки,
                      топ-5 продуктов, структура каналов.
   Заказы           — добавление, редактирование, удаление,
                      смена статуса, просрочка.
   Производство     — выпуск, брак, часы, себестоимость,
                      добавление и редактирование записей.
   Качество         — брак по причинам, потери, закрытие случаев.
   Финансы          — выручка, себестоимость, прибыль, рентабельность.
   Продажи          — заказы, средний чек, каналы.
   Каналы           — план/факт, CAC, конверсия.
   Кадры            — штат, ФОТ, приём и увольнение.
   Отчёты           — сводная таблица, CSV, планы, журнал действий.
   Справочник       — категории, продукция, цены.
   Данные           — источники данных, пользователи, роли,
                      пересоздание демо, бэкап SQL.

5. РЕДАКТИРОВАНИЕ ДАННЫХ
----------------------------------------------------------------
   Войти → раздел → строка таблицы → «Изменить».
   Откроется форма с заполненными полями → «Сохранить изменения».
   Дашборд пересчитывается сразу.

6. ЕСЛИ ЧТО-ТО СЛОМАЛИ
----------------------------------------------------------------
   «Данные» → «Пересоздать демо-данные» (только администратор).
   Вернутся цифры: 12 480 изделий, 8 540 000 ₽, брак 2,4 %, загрузка 87 %.
